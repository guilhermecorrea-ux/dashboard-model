---
name: instalar-empresa
description: Instala o BMB Dashboard para uma empresa (cria a cópia, conecta as fontes, publica o site e entrega o link). Use quando alguém pedir para instalar o dashboard, colar o link deste repositório pedindo instalação, ou disser "/instalar-empresa".
---

Siga o guia **`INSTALAR.md`**, na raiz do repositório, do começo ao fim. Ele é a fonte única do passo a passo:
conferir o computador, criar a cópia `dashboard-<empresa>`, entregar a lista de contas, conectar cada fonte,
conferir os números, colocar o site no ar, ligar o robô e entregar o link de acesso.
