# DataTable

Tabela para rankings e listas (produtos, clientes B2B, campanhas, contas a pagar), dentro de um Panel.

**O consumidor fornece:** colunas, linhas já ordenadas e, se houver, o link para a lista completa.

- Cabeçalho no estilo `label`. Primeira coluna alinhada à esquerda; números à direita, com algarismos tabulares.
- Divisórias em `line` só entre linhas, nunca verticais. Linha sob o mouse em `surface-raised`.
- Variação em DeltaChip na última coluna.
- No painel, mostre até 10 linhas e leve o resto para "Ver todos ›".
- Em telas estreitas, a tabela rola na horizontal dentro do painel, nunca a página.
